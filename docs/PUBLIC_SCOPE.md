# 公开范围

本候选包包含本次新写的 Markdown 案例、Mermaid 架构图、合成演示方案，以及一个 Python 标准库本地样例和运行说明。它没有导入源项目 Git 历史，也没有复制原项目源代码、原始内容或运行记录。

可公开候选：

- 通用工程问题与设计取舍。
- 已核实存在的组件职责与明确的未验证边界。
- 本人职责与 AI 协作方式。
- 现有公开 Radar 仓库链接。
- 尚未实现的合成演示设计。
- 为展示方法新写的本地审批／恢复样例；只使用合成数据，未接真实平台或模型。

本包不包含：雇主／客户源码和资料、个人知识库正文、原始阅读文章、连载正文与大纲、真实提示词快照、账号／密钥、生产地址和内部 IP、家庭住址、平台数据和私人 Git 远端。

该范围不等于已授权公开原项目源码。许可证与最终发布范围仍待作者决定；本文件没有向第三方授予源项目代码或素材许可。
