# 证据与核验范围

整理日期：2026-11-10。这里区分四种不同的证据，避免把项目文件与今天的运行结果混在一起。

| 证据 | 本包当前拥有的内容 | 能说明什么 | 不能说明什么 |
| --- | --- | --- | --- |
| 公开源代码 | Easton Radar 现有公开仓库 | 读者可以直接审阅该版本代码 | 线上服务健康、连续调度成功或全部结果正确 |
| 本地源码检查 | 另两个项目的指定模块已阅读，公开包仅写脱敏说明 | 所述核心机制有对应实现入口 | 读者现在可以从本包运行这些项目 |
| 历史验收记录 | 本地文档记录过真实业务或审稿接口核验 | 对应历史版本有记录 | 当前部署仍相同或本轮重跑通过 |
| 本轮语法检查 | 三份 Node.js 文件 `node --check`，六份 Python 文件 `ast.parse` 通过 | 指定文件语法可解析 | 功能、性能、数据安全和生产链路通过 |
| 本轮合成样例自测 | `python examples/editorial_workflow.py --self-check` 六项通过，含独立子进程恢复，接收端模拟提交数及回执数均为 1 | 本次本地 SQLite 模拟的审批与恢复行为可复现 | 原项目线上验收、真实网络故障或并发正确性 |

本次没有读取原小说、真实台账、私有知识正文、平台密钥或客户数据；没有启动源项目、触发模型／搜索、运行部署或对外写入。

本包没有声称：检索指标已提升多少、自动脱敏可靠、私有数据已由凭据彻底隔离、生成内容得到真实读者效果验证，或模型／平台请求达到严格 exactly-once。

已完成的[本地审批与恢复样例](../examples/README.md)提供固定合成输入、失败注入、输出断言和已知限制；它是本次新写的演示。更完整的知识检索、小说审稿台和信息简报合成演示仍见[演示设计](../examples/synthetic-demo-plan.md)，当前尚未实现。
